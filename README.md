# فضاء طلبة العربية – التعليم الابتدائي

واجهة عربية متجاوبة لطلبة تخصص اللغة العربية – التعليم الابتدائي، مهيأة للهواتف والحواسيب.

## الأقسام والخصائص
- صفحة رئيسية وروابط تنقل واضحة.
- فصل المحتوى بين المجموعة A (مدرج أ) والمجموعة B (مدرج د).
- حفظ اختيار المجموعة على الجهاز عبر التخزين المحلي للمتصفح.
- البحث داخل قائمة الدروس والمحاضرات المعروضة.
- عرض محاور كل مقياس ووحداته داخل نافذة مستقلة.
- إظهار الوحدة غير المنشورة بلون خافت مع عبارة «قريباً»، وإضاءة الوحدة عند نشر محاضرتها.
- قفل إدارة داخل نافذة المقياس يتيح نشر ملفات PDF أو حذفها بعد التحقق من رمز الإدارة.
- حفظ المحاضرات في Netlify Blobs لتظهر للمجموعتين ولجميع الزوار.

## النشر والتشغيل

### النشر مع دعم نشر المحاضرات
ميزة رفع المحاضرات وحذفها تحتاج إلى خدمة خلفية، لذلك يجب نشر المشروع عبر Netlify (وليس GitHub Pages وحده):

1. اربط مستودع GitHub هذا بموقع Netlify.
2. اترك إعدادات البناء كما هي في ملف `netlify.toml`.
3. من إعدادات الموقع في Netlify افتح **Environment variables** وأضف متغيراً باسم `ADMIN_CODE` وضع فيه رمز الإدارة الذي تختاره.
4. أعد نشر الموقع بعد إضافة المتغير.
5. افتح نافذة أي مقياس واضغط «إدارة المحاضرات» أسفل النافذة، ثم أدخل الرمز لنشر أو حذف ملفات PDF.

الحد الأقصى لحجم ملف المحاضرة 5.5 ميغابايت. تُحفظ الملفات في مخزن Netlify Blobs المشترك.

### GitHub Pages
يمكن فتح `index.html` مباشرة أو نشر الواجهة عبر GitHub Pages، لكن GitHub Pages لا يشغّل وظائف الخادم ولا يدعم رفع المحاضرات المشتركة. ستظهر الواجهة، لكن القفل والنشر والحذف لن تعمل حتى يتم ربط المشروع بخدمة Netlify وضبط `ADMIN_CODE`.

## ملاحظة
المحاور والوحدات المعروضة هي الهيكلة الدراسية الموجودة حالياً في بيانات المشروع، ويمكن تحديثها لاحقاً بما يطابق البرنامج الرسمي المعتمد.
