# فضاء طلبة العربية – التعليم الابتدائي

واجهة عربية متجاوبة لطلبة تخصص اللغة العربية – التعليم الابتدائي، مهيأة للهواتف والحواسيب.

## الأقسام والخصائص
- صفحة رئيسية وروابط تنقل واضحة.
- فصل المحتوى بين المجموعة A (مدرج أ) والمجموعة B (مدرج د).
- حفظ اختيار المجموعة على الجهاز عبر التخزين المحلي للمتصفح.
- البحث داخل قائمة الدروس والمحاضرات المعروضة.
- أقسام مستقلة للدروس والمحاضرات، التوقيت، الموارد، والإعلانات.
- تصميم عربي من اليمين إلى اليسار مع قائمة سفلية للهواتف.

## التشغيل والنشر
يمكن فتح `index.html` مباشرة، أو تفعيل GitHub Pages من إعدادات المستودع:
1. افتح **Settings** ثم **Pages**.
2. اختر **Deploy from a branch**.
3. اختر الفرع `main` والمجلد `/(root)` ثم احفظ.

## حدود النسخة الحالية
هذه نسخة واجهة أمامية تجريبية. البحث واختيار المجموعة يعملان داخل المتصفح، لكن لا يوجد حتى الآن تسجيل دخول حقيقي أو حسابات للأساتذة والطلبة أو قاعدة بيانات مشتركة. لذلك لا يمكن للأساتذة نشر الدروس أو رفع الملفات لتظهر تلقائياً لدى الطلبة بعد. يتطلب ذلك ربط المشروع بخدمة خلفية وقاعدة بيانات وتحديد صلاحيات الحسابات.

**ملاحظة:** أسماء المقاييس أو أي محتوى تجريبي ظاهر في الواجهة ليست بيانات رسمية منشورة من الأساتذة.
