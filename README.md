# فضاء طلبة العربية – التعليم الابتدائي

واجهة عربية متجاوبة لطلبة تخصص اللغة العربية – التعليم الابتدائي.

## المحتوى
- صفحة رئيسية للطلبة.
- فصل المحتوى حسب المجموعة A (مدرج أ) والمجموعة B (مدرج د).
- أقسام الدروس والمحاضرات، التوقيت، الموارد، والإعلانات.
- تصميم متجاوب مع الهواتف والحواسيب.

## التشغيل
افتح `index.html` مباشرة، أو فعّل GitHub Pages من إعدادات المستودع واجعل المصدر `main` والمجلد `/(root)`.

> هذه النسخة واجهة أولية؛ النشر الفعلي للدروس والتوقيت والإعلانات وربط حسابات الأساتذة يحتاج إلى إضافة تخزين وقاعدة بيانات وخدمات خلفية لاحقاً.
