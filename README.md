# فضاء طلبة العربية – التعليم الابتدائي

واجهة عربية متجاوبة لطلبة تخصص اللغة العربية – التعليم الابتدائي، مهيأة للهواتف والحواسيب.

## الأقسام والخصائص
- صفحة رئيسية وروابط تنقل واضحة.
- فصل المحتوى بين المجموعة A (مدرج أ) والمجموعة B (مدرج د).
- حفظ اختيار المجموعة على الجهاز عبر التخزين المحلي للمتصفح.
- البحث داخل قائمة الدروس والمحاضرات المعروضة.
- عرض محاور كل مقياس ووحداته داخل نافذة مستقلة.
- إظهار الوحدة غير المنشورة بلون خافت مع عبارة «قريباً»، وإضاءة الوحدة عند نشر محاضرتها.
- قفل إدارة داخل نافذة المقياس يتيح نشر ملفات PDF أو حذفها بعد التحقق من رمز الإدارة.
- تخزين ملفات المحاضرات المشتركة في Cloudflare R2 عبر Cloudflare Worker.

## النشر على Cloudflare Workers

يعتمد المشروع على Worker يخدم الواجهة الثابتة من `index.html` ويعالج مسارات إدارة المحاضرات:
- `GET /api/lessons`: قائمة مفاتيح المحاضرات المنشورة.
- `POST /api/lessons`: التحقق من رمز الإدارة.
- `GET /api/file?key=...`: فتح ملف PDF أو تنزيله بإضافة `download=1`.
- `POST /api/file?key=...`: رفع ملف PDF.
- `DELETE /api/file?key=...`: حذف ملف PDF.

### الإعداد المطلوب مرة واحدة

1. أنشئ Bucket في Cloudflare R2 بالاسم الدقيق `arabic-primary-lessons`.
2. في إعدادات Worker، أضف R2 Bucket Binding:
   - Variable name: `LESSONS_BUCKET`
   - R2 bucket: `arabic-primary-lessons`
3. أضف متغيراً سرياً باسم `ADMIN_CODE` وضع فيه رمز الإدارة الذي تختاره.
4. اربط مستودع GitHub بهذا الـ Worker، وتأكد أن إعدادات النشر تقرأ ملف `wrangler.jsonc` من جذر المستودع.
5. أمر النشر: `npx wrangler deploy`.

ملف `wrangler.jsonc` يحدد اسم Worker وربط الملفات الثابتة ومخزن R2. حد رفع ملف PDF هو 4.2 ميغابايت. يجب أن يبقى رمز `ADMIN_CODE` سرياً وألا يوضع داخل ملفات الواجهة أو GitHub.

## التوافق مع Netlify

أُبقيت ملفات Netlify ووظائفها مؤقتاً حتى يمكن الرجوع إلى الاستضافة السابقة أثناء اختبار Cloudflare. لا تحذف إعدادات Netlify أو مخزنها قبل التأكد من أن الرفع والعرض والحذف تعمل على Cloudflare.

## GitHub Pages

يمكن عرض الواجهة الثابتة عبر GitHub Pages، لكن إدارة المحاضرات المشتركة تحتاج إلى Worker ومخزن R2؛ لذلك لا تكفي GitHub Pages وحدها.
