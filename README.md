# فضاء طلبة العربية – التعليم الابتدائي

واجهة عربية متجاوبة لطلبة تخصص اللغة العربية – التعليم الابتدائي، مهيأة للهواتف والحواسيب.

## الأقسام والخصائص
- صفحة رئيسية وروابط تنقل واضحة.
- فصل المحتوى بين المجموعة A (مدرج أ) والمجموعة B (مدرج د).
- حفظ اختيار المجموعة على الجهاز عبر التخزين المحلي للمتصفح.
- البحث داخل قائمة الدروس والمحاضرات المعروضة.
- عرض محاور كل مقياس ووحداته داخل نافذة مستقلة.
- إظهار الوحدة غير المنشورة بلون خافت مع عبارة «قريباً»، وإضاءة الوحدة عند نشر محاضرتها.
- قفل إدارة داخل نافذة المقياس يتيح نشر ملفات PDF أو حذفها بعد التحقق من رمز الإدارة.
- تخزين ملفات المحاضرات المشتركة في Cloudflare R2 عبر Cloudflare Worker.

## النشر على Cloudflare Workers

يعتمد المشروع على Worker يخدم الواجهة الثابتة من `index.html` ويعالج مسارات إدارة المحاضرات:
- `GET /api/lessons`: قائمة مفاتيح المحاضرات المنشورة.
- `POST /api/lessons`: التحقق من رمز الإدارة.
- `GET /api/file?key=...`: فتح ملف PDF أو تنزيله بإضافة `download=1`.
- `POST /api/file?key=...`: رفع ملف PDF.
- `DELETE /api/file?key=...`: حذف ملف PDF.

### الإعداد المطلوب مرة واحدة

1. أنشئ Bucket في Cloudflare R2 بالاسم الدقيق `arabic-primary-lessons`.
2. في إعدادات Worker، أضف R2 Bucket Binding:
   - Variable name: `LESSONS_BUCKET`
   - R2 bucket: `arabic-primary-lessons`
3. أضف متغيراً سرياً باسم `ADMIN_CODE` وضع فيه رمز الإدارة الذي تختاره.
4. اربط مستودع GitHub بهذا الـ Worker، وتأكد أن إعدادات النشر تقرأ ملف `wrangler.jsonc` من جذر المستودع.
5. أمر النشر: `npx wrangler deploy`.

ملف `wrangler.jsonc` يحدد اسم Worker وربط الملفات الثابتة ومخزن R2. حد رفع ملف PDF هو 4.2 ميغابايت. يجب أن يبقى رمز `ADMIN_CODE` سرياً وألا يوضع داخل ملفات الواجهة أو GitHub.

## التوافق مع Netlify

أُبقيت ملفات Netlify ووظائفها مؤقتاً حتى يمكن الرجوع إلى الاستضافة السابقة أثناء اختبار Cloudflare. لا تحذف إعدادات Netlify أو مخزنها قبل التأكد من أن الرفع والعرض والحذف تعمل على Cloudflare.

## GitHub Pages

يمكن عرض الواجهة الثابتة عبر GitHub Pages، لكن إدارة المحاضرات المشتركة تحتاج إلى Worker ومخزن R2؛ لذلك لا تكفي GitHub Pages وحدها.

## النشر الثابت للقوائم العامة (يخفف الطلبات على Worker)

الصفحات تقرأ الدروس والإعلانات والموارد المعتمدة والجدول الأكاديمي من ملفات ثابتة في `data/` (قراءتها بلا حد يومي)، وإن غابت ترجع للـ API تلقائياً. بعد أي تعديل (رفع درس، إعلان، اعتماد مورد، حفظ الإدارة الأكاديمية) ينتظر الـ Worker نحو 10 ثوانٍ ثم يكتب الملفات المتغيرة في GitHub بإيداع واحد، فيعيد Cloudflare البناء والنشر.

### إعداد مطلوب مرة واحدة
أضف في Worker (Settings → Variables and Secrets):
- `GITHUB_TOKEN` (Secret): رمز GitHub دقيق الصلاحيات (Fine-grained) على هذا المستودع فقط، بصلاحية `Contents: Read and write`.
- `GITHUB_REPO`: اسم المستودع بصيغة `owner/repo`.
- `GITHUB_BRANCH` (اختياري): الفرع الذي يبني منه Cloudflare، والافتراضي `main`.

بعد النشر: سجّل دخول الإدارة مرة واحدة (أو استدعِ `POST /api/publish` برمز الإدارة) لتُنشأ الملفات الأولى. المشرفون ومن عدّل للتو يقرؤون من الـ API ليروا أحدث نسخة فوراً.

## استعادة الحساب («هذا حسابي»)

- يظهر الزر فقط بعد إدخال كلمة مرور خاطئة. الطلب يحمل: الاسم، تاريخ الميلاد، وصورة البطاقة بعد تغطية وجه الطالبة بالأسود داخل المتصفح (الوجه لا يغادر جهازها).
- يُسجَّل لكل حساب قائمة أجهزته (النوع والنظام والمتصفح وآخر استعمال). الطلب من جهاز معروف للحساب يُوسَم «موثوق ✅» وغيره «غير معروف ⚠️».
- المالك يرى صورة البطاقة في تبويب «الطلبات»، وتُحذف تلقائياً بمجرد قراره (قبول أو رفض).
- القبول لا يغيّر شيئاً فوراً: يُجدوِل التنفيذ. المهلة تُحسب من وقت الطلب: 24 ساعة لجهاز غير معروف، وساعة لجهاز موثوق (الثابتان `CLAIM_DELAY_MS` و`CLAIM_DELAY_TRUSTED_MS` في `src/index.js`). زر «ننفّذ الآن» يتجاوز المهلة.
- عند التنفيذ: تُستبدل كلمة المرور، وتُلغى كل الجلسات القديمة، ويبقى جهاز الطالب وحده.
- خلال المهلة يظهر لصاحب الحساب (عند دخوله) شريط «هل هذا أنت؟» مع «لا، ارفض»: يُلغى الطلب فوراً ويظهر تنبيه أحمر في صفحة الإدارة.
- كل الطلبات والقرارات في تبويب «الاستعادة» (السجل).
- التنفيذ بعد المهلة يتم بـ Cron كل 10 دقائق (مضاف في `wrangler.jsonc` تحت `triggers`) وأيضاً عند أول تعامل مع الحساب بعد انتهاء المهلة.

## المجموعات والدروس (ربط التوقيت بالدروس والرئيسية)

- مجموعات كل سنة جامعية تُدار من «إدارة البرنامج الأكاديمي ← التوقيت». أي مجموعة تُضاف أو تُعدَّل أو تُحذف هناك تظهر تلقائياً كزر في صفحة **الدروس** وفي قسم **الدروس والمحاضرات** بالرئيسية (لكل سنة مجموعاتها).
- رمز المجموعة حرف من A إلى Z (أول حرف غير مستعمل عند الإضافة) ويدخل في مفتاح الدرس. الخادم يقبل الآن مفاتيح أي حرف.
- رمز إدارة الدروس لمجموعة جديدة (غير A وB): السر `ADMIN_CODE_<الحرف>` (مثل `ADMIN_CODE_C`) إن وُجد، وإلا يُقبل رمز المالك `ADMIN_CODE_MOD`.
- قسم الرئيسية يعرض **آخر الدروس المنشورة** (الأحدث في بطاقة بارزة ثم 4 سابقة) للمجموعة والسنة والسداسي المختارين، وتتغير قائمتاه مع قائمتي «المواد والمقاييس».
